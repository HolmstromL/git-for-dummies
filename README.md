# Git for dummies
To ensure mutual understanding of Git and the Git workflow, this document was produced to be used as a handbook within [Paast Productions](https://github.com/Paast-Productions). The contents of the document may be applied to other projects, but certain decisions have been made which may not make sense in other projects. Keep this in mind before applying practices from this handbook.

## Disclosure
In this document, some features of Git and Gitflow, as well as ways to work with them, are explained. While some aspects are true in general scenarios, some aspects may be explained as true despite them only being so for this specific project. Before applying certain ways of working outside of this project, ensure that they are correct for your specific use case.
